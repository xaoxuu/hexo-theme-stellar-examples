这里没有复杂的导航，也没有抢夺注意力的侧栏。它适合随笔、阅读笔记，以及那些值得被慢慢写下来的故事。

打开一篇文章，视线会自然停留在标题、正文和目录上；需要搜索或调整外观时，入口仍然留在顶部。

## 从一个段落开始

轻量并不等于缺少表达能力。稳定的行宽、清楚的标题层级和克制的留白，会让读者更容易理解一段文字为什么值得继续读下去。

> 好的阅读界面不替内容发言，只帮助内容被看见。

写作时也可以保留必要的技术细节。例如，一条最小的 Hexo 构建命令仍然应该清楚、可复制：

```bash
npx hexo clean && npx hexo generate
```
