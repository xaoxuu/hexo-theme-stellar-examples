打开空白文档时，先写标题往往写不出来。标题要求你提前知道文章的全貌，而多数时候，全貌是在写字的过程中慢慢浮出来的。

<!-- more -->

## 第一段只负责开始

我给自己定的规则很短：第一段先写一个具体场景，句子可以不漂亮，只要真实。比如“周三晚上整理书架时，翻出一本三年前买的书”，比“谈谈阅读习惯”更容易继续写下去。

{% box color:cyan 第一段包含什么 %}
一个时间，一个地点，一个动作。

还可以加一句当时的想法。写不下去时，就从这句话往下接。
{% endbox %}

## 标题从最后一段里找

写完正文再回头看，你会发现某个句子已经把全文说清楚了。把它调整得短一些，标题就有了。这样的标题带着文章自己的语气，后续修改也不必别扭。

{% quot 写作的顺序，和阅读的顺序可以不一样。 %}

## 标题留到最后也可以

如果全文写完还是没有合适的标题，就先把文章放一晚。第二天重新读一遍，通常在开头或结尾就能找到那句话。

{% folding color:yellow 一份简单的检查清单 %}
- 第一段是否写出了具体场景？
- 每段是否只推进一个意思？
- 结尾是否给出了可以继续的方向？
{% endfolding %}

标题、摘要和标签补齐以后，这篇稿子就可以进入发布流程了。
