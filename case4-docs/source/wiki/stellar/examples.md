## 开源 demo 示例

[xaoxuu/hexo-theme-stellar-examples](https://github.com/xaoxuu/hexo-theme-stellar-examples/) 提供四套完整 Blueprint：

| 源码目录 / Blueprint | 场景 | 默认外观 |
| :-- | :-- | :-- |
| `case1-lightblog` / `lightblog` | 单栏极简博客，适合长文与低干扰阅读 | Flat |
| `case2-blog` / `blog` | 经典侧边栏博客，适合技术、阅读与生活内容 | Card |
| `case3-knowledge` / `knowledge` | 内容聚合型个人知识库 | Glass |
| `case4-docs` / `docs` | 单项目文档站，项目首页位于根路径 | Card |
