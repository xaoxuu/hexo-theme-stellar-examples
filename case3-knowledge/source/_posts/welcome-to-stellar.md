这个示例使用 **Glass** 外观，同时包含博客文章、系统化整理专栏，以及两个拥有独立目录的 Wiki 知识库。你可以按时间阅读记录，也可以按任务查询已经整理好的指南。

<!-- more -->

## 先选择一个知识库

{% grid bg:card w:220px gap:16px %}
<!-- cell -->
**个人知识管理**

从保留材料的上下文开始，学习如何整理独立笔记，再通过回访和实际应用更新内容。

[阅读个人知识管理](../../wiki/knowledge-management/)

<!-- cell -->
**Stellar 建站手册**

从内容归属出发，理解博客与 Wiki 的区别，配置阅读入口，并完成一次站点检查。

[阅读 Stellar 建站手册](../../wiki/site-handbook/)
{% endgrid %}

两个知识库各有首页与三篇指南，目录中的上下篇按学习顺序排列。顶部“知识库”入口可以随时返回项目列表。

## 让不同内容互相连接

博客记录一次具体尝试，专栏连接连续的思考，知识库维护可以反复查询的方法。写完一篇日志后，可以把其中稳定的做法提炼进 Wiki，再在文章里链接到对应指南。

| 入口 | 作用 |
| --- | --- |
| 博客 | 按时间阅读新的记录 |
| 分类 | 稳定的知识领域 |
| 标签 | 灵活的内容关联 |
| 专栏 | 按顺序阅读一组文章 |
| 知识库 | 按主题查询有独立目录的指南 |
