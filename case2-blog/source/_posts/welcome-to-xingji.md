## 从完整导航开始

Classic Blueprint 提供文章、归档、分类和标签构成的常规博客路径，Card Visual Style 则用明确的边界组织每一条内容。

这里还保留一个“独立博客实践”专栏，把建站过程中的连续思考聚合起来。

> 个人博客的价值不在于一次写完，而在于长期留下可以重新发现的轨迹。

```js
const site = {
  name: "星迹",
  blueprint: "classic",
  style: "card"
};
```

| 入口 | 用途 |

| 专栏 | 组织需要连续阅读的文章 |
